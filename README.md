# 静读天下墨水屏模式（MoonReaderInk）

一个基于 **LSPosed / Xposed** 的 UI 适配模块：把「静读天下」阅读器里偏蓝、偏灰的界面改成适合电子墨水屏的**白底黑字**，并把 EPUB 注释弹窗里的链接文字改黑、去掉下划线。

## 功能

| 功能         | 说明                                                                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 链接 Hook    | 把 EPUB 注释弹窗里 `Html.fromHtml()` 生成的原生 `URLSpan` 换成自定义 Span，跟随 App 自身的「链接颜色」并去掉下划线，保留点击            |
| 墨水屏主题   | 彩色 / 灰阶背景转纯白、文字与图标转黑，状态栏改白底黑图标，顶部加黑色分割线，开关 / 单选 / 分段按钮换成黑白样式，蓝色默认封面与悬浮按钮重绘 |
| 总开关       | 一键停用上面两个功能；关闭后模块一个 hook 都不注册                                                                                          |
| 模块设置入口 | 在目标 App「设置选项」页最底部加入口；无 Root / LSPatch 场景模块未单独安装时，直接在目标 App 内弹出设置面板                                 |

三个功能各有独立开关，默认全部开启。开关读取优先级：
**系统属性 > 目标 App 内嵌面板 > 模块设置页 > 默认开启**。默认作用域（推荐列表）包含原版
`com.flyersoft.moonreaderp` 与改包名的共存版 `com.flyersoft.moonreaderps`，两者互不干扰。

## 环境要求与构建

| 依赖        | 说明                                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------------------- |
| Python      | 3.9+，仅标准库                                                                                                 |
| JDK         | 17（需要 `java` / `javac` / `keytool`）                                                                  |
| Android SDK | 任一 `platforms/android-33`（或更高）的 `android.jar`、`build-tools` 35.0.0（或含 `aapt2` 的其它版本） |

工具链按顺序自动查找，可用环境变量覆盖：

| 变量                                                          | 用途                                 |
| ------------------------------------------------------------- | ------------------------------------ |
| `JAVA_HOME` / `MRI_JDK_BIN`                               | JDK 根目录 / 直接指向 `bin`        |
| `ANDROID_HOME` / `ANDROID_SDK_ROOT` / `MRI_ANDROID_SDK` | Android SDK 根目录                   |
| `MRI_BUILD_TOOLS`                                           | 指定 build-tools 版本，如 `35.0.0` |

仓库本身不含任何个人路径或凭据。

```bash
python build.py              # 调试版 -> out/MoonReaderInk-debug.apk
python build.py --release    # 正式版 -> out/MoonReaderInk-release.apk
```

`assets/xposed_init`。

## 安装与使用（有 Root）

1. 设备装有 LSPosed（或兼容的 Xposed 实现）；本项目在 Android 10 上验证。无 Root 设备见下一节。
2. 安装构建出的 APK，在框架管理器里启用模块，并**手动勾选作用域**——推荐列表
   （`res/values/arrays.xml`）只是建议值，不会自动写进已保存的作用域。
3. 强制停止并重新打开目标阅读器。
4. 在模块设置页切换三个开关：可从框架管理器的「模块设置」进入，也可从目标 App
   「设置选项」页**最底部**的「墨水屏模式 · 模块设置」进入；改动需重启目标 App 生效。
   设置页本身就是白底黑字的墨水屏样式，不需要额外配置；「关于」对话框里有可点击的
   项目主页链接（https://github.com/liuqianhe/MoonReaderInk）。

设置页里的提示是通用的 `adb shell setprop` 命令，仓库内不依赖任何外围脚本。
有 Root 时可用系统属性强制覆盖（优先级高于两个设置面板）：

```bash
adb shell setprop persist.moonreader.ink.master 0       # 总开关，0 关 / 1 开
adb shell setprop persist.moonreader.ink.link_hook 0    # 链接 Hook
adb shell setprop persist.moonreader.ink.theme 0        # 墨水屏主题
adb shell setprop persist.moonreader.ink.master ""      # 清空，交还设置页
```

## 无 Root 设备：LSPatch 等修补工具

没有 Root 的设备可以用 [LSPatch](https://github.com/LSPosed/LSPatch) 之类的工具，把本模块
**嵌入目标 App 的 APK** 后在无 Root 环境加载（便携模式），或依赖 LSPatch 管理器运行
（本地模式）。大致流程：安装 LSPatch 管理器 → 选择目标应用与修补输出目录 → 嵌入本模块
APK → 开始修补 → 安装修补后的 APK。

> **⚠️ 签名与数据丢失风险（务必先读，别直接当"升级"装）**

- 修补后的 APK 由修补工具**重新签名**，与原版应用签名不同；即使版本号一样，也**无法覆盖
  安装**，通常必须**先卸载原版、再安装修补版**。
- 即便模块内容一个字没改，**重新修补**（换修补工具版本、换管理器、重装修补器、增删模块、
  换了签名密钥 / 换了设备）也可能生成**不同的签名**。于是下次想"像升级版本那样"覆盖安装时，
  可能会因为签名不一致而失败，只能再次卸载重装。
- 卸载会清掉该应用的**本地数据**：书架、阅读进度、书签 / 笔记、账号登录状态、字体与自定义
  设置等。修补前请务必用应用自带的「备份 / 恢复」或系统 / 第三方备份工具完整备份，
  并确认备份文件**不在被卸载应用的私有目录里**；有条件先导出一份确认可恢复。
- **本项目不对任何数据丢失、账号异常、应用无法启动、签名检测导致的第三方跳转失败或设备
  问题负责**，由此产生的一切后果由使用者自行承担。不确定时请先在备用设备、共存版或无关
  紧要的账号上试。
- 修补版属于非官方修改包，部分应用会检测签名完整性；本项目不提供绕过检测的能力。

无 Root 场景下模块 APK 通常**不会作为独立应用安装**，框架管理器里也就没有「模块设置」
入口。为此本项目在目标 App「设置选项」页最底部加了 **「墨水屏模式 · 模块设置」** 条目：
点击会先尝试打开模块自身的设置页；若模块未单独安装，则直接在目标 App 进程内弹出设置面板。
内嵌面板把开关写进目标 App 自己的 SharedPreferences，Hook 用 `XSharedPreferences`
直接读取，因此**不依赖模块 APK 是否安装**。

## 实现要点与已知限制

- 主题覆盖 `Resources` 取色 / `getDrawable`、View 与 TextView / ImageView 的 setter、
  状态栏，并在 `Activity.onResume`、`Dialog.show`、`View.onAttachedToWindow` 时扫描控件树。
- 蓝底白字的徽标**原地改像素**而不是替换 Bitmap 对象（Fresco 会复用 `inBitmap`）；
  MaterialButton 只做 tint 不替换 background（App 内部会强转具体类型）。
- 顶部分割线**只按资源 id** 定位面包屑容器，不用屏幕坐标判断——列表滚动后条目会滚到
  屏幕上方，按坐标猜会不断给条目误加黑线。
- 模块代码运行在目标进程里读不到自身 `res/`，因此图标以 Base64 内嵌、资源 id 同时按
  资源名解析兜底。
- **仅针对静读天下 10.8 做过验证**，属于版本相关的实验性 Hook；目标应用更新后可能失效，
  也可能出现样式错位。请优先在备用设备 / 共存版上试用。
- 书籍真实封面、书内图片与正文内容都不会被改动；模块不写入目标应用的任何文件。
- 分割线固定在面包屑容器底部；没有该容器的页面不会自动加线。
- 「选项」页的模块设置入口只按 `id/pvTopLine` 精确挂载、带 tag 判重，不会重复添加；
  抽屉底部「设置选项 / 软件说明 / 晚上模式 / 退出」四个文字按 id 与文本内容双重判断，
  在 `onDraw` 之前强制纯黑（App 用 XML / ColorStateList 上色会覆盖扫描结果）。
- 模块设置页与无 Root 内嵌面板共用 `SettingsUi.build()`，全部控件纯代码自绘黑白；
  `SettingsActivity` 用 `Theme.Material.Light.NoActionBar` + 白底黑图标状态栏，
  标题栏与分割线由 UI 自绘，避免系统 ActionBar 的浅灰背景和重复标题。
- Switch 的自定义 track / thumb 用 `StateListDrawable` **不会**随 checked 状态可靠刷新，
  改为在 `OnCheckedChangeListener` 里按状态直接换 drawable；对话框黑框要画在内容 View
  上（设在 Window 背景上的描边会被内容盖住），并用 `setDimAmount(0f)` 去掉深灰遮罩。
- 内嵌设置面板与模块设置页写入的是**不同**的 prefs 文件；同时用过时以系统属性优先、
  内嵌面板次之，详见上面的开关优先级。
